# GM Escalade 2-Mode Hybrid Expert

Guidelines and conventions for AI assistants working on this codebase:

- **Framework**: TanStack Start with Vite, React 19, and Tailwind CSS.
- **Testing**: Vitest with React Testing Library. Maintain high test coverage (>80%) across `src/lib` and `src/components`. Run tests with `npm test`.
- **Git workflow**: Maintain a clean, working commit history. Pre-commit hooks run automatically via Husky to verify all tests pass before commits.
